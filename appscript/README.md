# نظام إدارة الكادر الطبي — نسخة Google Apps Script

تجمع عسير الصحي · إدارة المستشفيات والمراكز المتخصصة

نسخة من النظام تعمل على Google Apps Script وتخزّن البيانات في Google Sheets،
بالوحدات السبع كاملة ونفس قواعد العمل.

---

## ⚠️ اقرأ هذا أولاً

قبل إدخال أي بيانات حقيقية، انتبه لثلاث نقاط:

**١) البيانات تخرج من التجمع.** Apps Script يعمل على سحابة Google، فبيانات
المنسوبين تُخزَّن على خوادم Google خارج المملكة. هذا قد يصطدم بضوابط الهيئة
الوطنية للأمن السيبراني ونظام حماية البيانات الشخصية. **احصل على اعتماد الجهة
قبل الإدخال الحقيقي.**

**٢) الإنترنت إلزامي.** لا تعمل هذه النسخة على شبكة داخلية مقطوعة، بعكس نسخة
Django التي تعمل بلا اتصال.

**٣) Sheets ليست قاعدة بيانات.** الضمانات التالية مكتوبة في الشيفرة لا مفروضة
من المحرّك، وهي أضعف بطبيعتها:

| الضمان | في Django | هنا |
| --- | --- | --- |
| تفرُّد رقم الهوية | قيد في قاعدة البيانات | فحص داخل قفل برمجي |
| منع حذف منشأة مستخدَمة | `on_delete=PROTECT` | فحص برمجي |
| المعاملات | معاملة حقيقية | قفل واحد عام |
| الأداء | فهارس | قراءة الورقة كاملة لكل طلب |

لذلك: **احتفظ بنسخة Django** كمرجع، واستخدم هذه النسخة حيث يناسب.

## التركيب

### ١) أنشئ مشروع Apps Script

اذهب إلى <https://script.google.com> ← **New project**.

### ٢) انسخ الملفات

في المحرر، أنشئ الملفات التالية وانسخ محتوى كل واحد:

**ملفات السكربت** (زر `+` ← Script) — احذف `Code.gs` الافتراضي:

```
Config.gs       Db.gs          Auth.gs        Setup.gs
Employees.gs    Leaves.gs      Settings.gs    Users.gs
ActivityLog.gs  Dashboard.gs   Export.gs      Reconcile.gs
WebApp.gs
```

**ملفات HTML** (زر `+` ← HTML):

```
Index.html      Styles.html    JavaScript.html    NoAccess.html
```

> في Apps Script تُكتب أسماء ملفات HTML بلا الامتداد، فاكتب `Index` و`Styles`
> و`JavaScript` و`NoAccess`.

### ٣) اضبط المانيفست

من **Project Settings** فعّل **Show "appsscript.json" manifest file**، ثم
افتح `appsscript.json` وانسخ محتوى الملف المرفق فوقه.

### ٤) فعّل خدمة Drive المتقدمة

من القائمة الجانبية **Services** ← `+` ← **Drive API** ← اختر الإصدار **v2**
← **Add**. (تحتاجها أداة المطابقة لتحويل ملف Excel.)

### ٥) شغّل التهيئة مرة واحدة

من شريط المحرر اختر الدالة `setupSystem` ثم **Run**. سيطلب منك Google
الموافقة على الصلاحيات — وافق.

تُنشئ التهيئة:
- جدول بيانات جديد في Drive باسم «نظام إدارة الكادر الطبي — تجمع عسير الصحي»
- الأوراق التسع بترويساتها
- **١٩٠ جنسية** مزروعة ومرتّبة («سعودي» أولاً)
- حسابك كأول **مدير نظام**

انظر **Execution log** لرابط جدول البيانات.

### ٦) انشر تطبيق الويب

**Deploy** ← **New deployment** ← الترس ← **Web app**:

| الإعداد | القيمة |
| --- | --- |
| Execute as | **Me** |
| Who has access | **Anyone with Google account** |

> **لماذا «Me»؟** ليصل السكربت إلى جدول البيانات دون مشاركته مع المستخدمين.
> لو شاركت الجدول مباشرةً لرأى كل مستخدم بيانات كل المنشآت. فصل المنشآت
> مفروض في الشيفرة وحدها، فلا تشارك الجدول مع أحد.

انسخ **Web app URL** ووزّعه على المستخدمين.

## أول تشغيل

رتّب الخطوات هكذا — يوفّر إعادة عمل كبيرة:

1. **إعدادات النظام** ← أضف **المنشآت** أولاً
2. ثم **الأقسام** و**التخصصات**
3. **الصلاحيات** ← أضف حساباً لكل منشأة (بريد Google، صلاحية «حساب منشأة»، واربطه بمنشأته)
4. ابدأ تسجيل الموظفين

الجنسيات جاهزة بـ ١٩٠ جنسية، وتضيف عليها وقت ما تحب.

| **لوحة القيادة** | إحصاءات فورية و٤ بطاقات تنبيه (عقود وتصنيفات منتهية/وشيكة) |

| **سجل النشاطات** | تدقيق آخر ٣٠ يوماً مع «منذ كم يوم» |

## الصلاحيات

| الإجراء | مدير النظام | حساب منشأة |
| --- | --- | --- |
| موظفو منشأته | ✅ | ✅ |
| موظفو المنشآت الأخرى | ✅ | ❌ |
| إضافة وتعديل | ✅ | في منشأته فقط |
| الأرشفة والاستعادة | ✅ | في منشأته فقط |
| الحذف النهائي | ✅ | ❌ |
| تصدير Excel | كل المنشآت | منشأته فقط |
| مطابقة Excel | ✅ | ❌ |
| المستخدمون والإعدادات | ✅ | ❌ |
| سجل النشاطات | ✅ | ❌ |

**الفشل آمن:** بريد غير مسجَّل أو حساب معطَّل أو حساب فرعي بلا منشأة
→ **لا يرى شيئاً**، لا كل شيء.

**لا كلمات مرور:** الهوية من حساب Google. الجدول يربط البريد بالصلاحية
والمنشأة فقط.

## قواعد العمل المطبَّقة

مفروضة في الخادم لا في المتصفح — تصمد حتى لو استُدعيت الدالة من خارج الواجهة.

| الحقل | القاعدة |
| --- | --- |
| تاريخ الميلاد | العمر أكبر من ٢٠ عاماً |
| فئة الموظف = **خدمة مدنية** | تختفي تواريخ العقد، ويُمحى ما كان مسجَّلاً |
| فئة الموظف = غير ذلك | تاريخ نهاية العقد إلزامي |
| تاريخا العقد | النهاية بعد البداية |
| حالة التصنيف = **مصنف** | رقم التصنيف وتاريخ انتهائه إلزاميان معاً |
| حالة التصنيف = **غير مصنف** | يُمحى الرقم والتاريخ |
| رقم الهوية · الرقم الوظيفي | لا يتكرران |
| النقل للأرشيف | سبب إلزامي، بحد ٥٠٠ حرف |
| حذف عنصر مرجعي مستخدَم | مرفوض مع بيان عدد المرتبطين |
| إعادة تسمية عنصر مرجعي | تسري على كل السجلات والحسابات |

## الصيانة

**النسخ الاحتياطي:** جدول البيانات هو كل شيء. من Drive: **Make a copy**
دورياً، أو **File ← Version history** للرجوع لنسخة سابقة.

**إضافة حقل جديد:** أضف اسم العمود في نهاية المصفوفة المناسبة في
`COLUMNS` داخل `Config.gs`، ثم شغّل `setupSystem` مرة أخرى — يكتب الترويسة
الجديدة دون المساس بالبيانات.

**تعديل مُدد التنبيه:** `CONTRACT_ALERT_DAYS` و`CLASSIFICATION_ALERT_DAYS`
في `Config.gs`.

**بعد أي تعديل على الشيفرة:** لازم **Deploy ← Manage deployments ← ✎ ←
Version: New version ← Deploy**، وإلا بقي المنشور على النسخة القديمة.

## التحقق

جرى اختبار منطق النظام بـ **٤١ اختباراً** تغطي: زرع الجنسيات وترتيبها،
وحدّ العمر، وقواعد العقد والتصنيف، والتفرُّد، والأرشفة وسببها، وعزل بيانات
المنشآت، وحماية البيانات المرجعية من الحذف، وسريان إعادة التسمية، والتنبيهات،
وحماية حساب المدير، وتمييز العدد في العربية، وتحييد صيغ Excel.
